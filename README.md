# University WEB Map Navigator 2.0

**Вторая версия навигационной системы университетского кампуса**  
*Проект в стадии разработки*

## Текущее состояние проекта

### Реализованный функционал
- Интерактивная карта университета
- Поиск аудиторий и кабинетов
- Отображение поэтажных планов
- Алгоритм Беллмана-Форда для расчета маршрутов

### Ограничения текущей версии
- **Бекенд**: Частично реализован, требует доработки
- **Создание маршрутов**: Временно не функционирует
- **Интеграция**: Алгоритм маршрутизации требует подключения к UI

## Технические детали

**Алгоритм маршрутизации**: Беллмана-Форда  
**Статус**: Прототип  
**Версия**: 2.0 (development)
